# Distribution

Atto's total supply of 18 billion coins was created at genesis—no new coins can ever be minted. These existing coins enter circulation gradually through the faucet, mining, staking rewards, and contribution rewards.

Distribution rates can be adjusted using the [Growth Stability Index (GSI)](/docs/growth-stability-index), which scales configured rates in response to market data.

:::note Current distribution rules
Eligibility, rates, and timing vary by distribution route and may change. The GSI is an input to the distribution mechanism; it does not set or ensure a market price.
:::

## Distribution Programs

### Faucet

The [faucet](/faucet) lets users request a small amount of Atto under the current faucet rules. It's a simple way for newcomers to start using the network without buying Atto first or completing technical setup.

### Mining (Folding@Home)

Through the [Folding@Home integration](/docs/mining), participants contribute computing power to medical research and may receive mining rewards under the current reward policy.

### Staking

In [Open Representative Voting](/docs/whitepaper#consensus-mechanism-open-representative-voting), representatives vote on transactions using delegated voting weight. Separately, eligible accounts delegated to participating voters may receive staking rewards under the current reward policy. Running a voter node or receiving delegated weight does not by itself create reward eligibility. See the [staking voter guide](/blog/how-to-host-a-staking-voter) for setup instructions.

### Contribution Rewards

Community members may earn rewards for accepted pull requests that improve Atto:

- Software development and code contributions
- Documentation, tutorials, and educational content
- Tests, tooling, integrations, UI polish, and fixes
- Private critical vulnerability reporting as the security exception

Under the current workflow, reward-eligible PRs receive a tier label before merge and the corresponding ATTO reward may be distributed after merge. For larger work, check in first because not every contribution will be accepted. For details, see [Rewards for Contributions](/docs/reward-for-contributions).

# Read-only Atto API explorer {#live-network}

Use the public live node to inspect current data or watch protocol activity. This page exposes only read and stream methods from the Commons node client. It cannot sign, create work, publish, or modify an account.

See the [Node API endpoint reference](/api/node) for request and response contracts.

Look up node time, an account, a transaction or an account entry, then start a live stream when you want to inspect incoming protocol events. No wallet secret is needed.

<NetworkTools />

For general account and transaction browsing, [browse the Atto explorer](/explorer).

:::warning Public endpoint
Queries go to `https://gatekeeper.live.application.atto.cash`. The operator can observe ordinary request metadata plus any address or hash you submit. Use your own node when that metadata is sensitive.
:::

Streams are not background subscriptions. They start only after you press **Start stream**, stop when you press **Stop stream**, and are cancelled when the component unmounts. A dropped stream reconnects with bounded backoff only while it remains explicitly enabled.
